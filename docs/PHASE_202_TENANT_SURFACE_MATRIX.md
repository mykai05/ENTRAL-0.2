## Release rule

An applicable surface fails closed unless its authenticated identity, actor, tenant, organization, and database policy agree. A new surface or a material expansion of an existing surface requires this matrix, the Phase 202 static gate, the PostgreSQL denial suite, and the relevant product/browser test to be updated before release.

The matrix is evidence, not authority. Runtime authority remains in the canonical contracts, `entral.app_users`, `IdentityActor`, `TenantActorAssignment`, `TenantBoundary`, PostgreSQL RLS, and exact role grants.
